FAQ

Preguntas frecuentes.

¿Qué es un Discovery Pack?

Es una selección de 5 muestras pensada para probar distintas fragancias antes de elegir un perfume full size.

¿Cómo funciona el descuento?

En este prototipo podés usar el código SECRET25 en el carrito para descontar $25.000 sobre perfumes.

¿Puedo usar el beneficio más de una vez?

Para el modelo real sería de un solo uso. En este prototipo académico el cupón sirve para demostrar la mecánica.

¿Cuántas muestras vienen?

Cada Discovery Pack incluye 5 muestras de 2 ml.
